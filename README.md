# RainReady2Go

Rain protection for students, sold right on campus. A student venture by 3rd Year BSIT students at Cebu Eastern College.

## Features
- Rain gear catalog with prices
- Order form with quantity, pickup spot and payment choice
- Campus pickup spots and student survey results
